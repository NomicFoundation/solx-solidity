# Gas-observability divergences: state semantics match legacy/via-ir, but the
# tests pin out-of-gas outcomes that LLVM-optimized code does not reproduce
# (LLVM does not model gas, so it removes or folds gas-metered dead operations).
# Do not re-triage as semantic bugs.
#
# array_function_pointers: f() provably reverts on all paths and nothing reads
# heap memory, so DSE deletes the 58MB zero-fill calldatacopy -> no memory
# expansion -> Panic(0x51) with returndata instead of OOG (empty returndata).
#
# array_storage_push_empty: keccak256 of the constant slot word is folded to a
# constant and redundant length sloads/bounds checks are eliminated, so
# pushEmpty(38869) finishes under the 100M gas limit instead of OOG.

# the legacy pipeline, and our target is legacy-codegen parity. Mismatches here
# are expected where the pinned expectation encodes a via-ir/legacy semantic
# fork; do not treat as actionable without checking which side the expectation
# pins.
#
# Verified by-design (initialization-order fork, docs "IR breaking changes"):
# legacy runs ALL state-var initializers base->derived before ANY constructor
# body (ContractCompiler.cpp:155); via-ir interleaves per contract. The three
# init-order tests pin the via-ir interleaving (e.g. y() -> 42 where legacy
# and this pipeline correctly yield 0).
